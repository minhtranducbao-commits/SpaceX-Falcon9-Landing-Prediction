# SpaceX Falcon 9 First Stage Landing Prediction
*IBM Data Science Professional Certificate - Capstone Project*

## 🚀 Project Overview
The goal of this project is to predict whether the first stage of the SpaceX Falcon 9 rocket will land successfully. Predicting landing success helps commercial competitors (like Space Y) estimate launch costs and evaluate reusable rocket economics.

## 📂 Repository Structure
- `1_data_collection_api.ipynb`: Data collection via SpaceX REST API.
- `2_data_collection_web_scraping.ipynb`: Web scraping launch data from Wikipedia using BeautifulSoup.
- `3_data_wrangling.ipynb`: Data cleaning, missing value imputation, and target encoding.
- `4_eda_matplotlib_seaborn.ipynb`: Exploratory Data Analysis using Matplotlib and Seaborn.
- `5_eda_sql.ipynb`: Database creation and SQL querying.
- `6_interactive_map_folium.ipynb`: Spatial analysis using Folium maps.
- `7_interactive_dashboard_plotly.ipynb`: Plotly Dash interactive web application.
- `8_predictive_analysis_ml.ipynb`: Machine learning classification models (Logistic Regression, SVM, Decision Tree, KNN).
- `README.md`: Project description and overview.

## 🛠️ Technologies Used
- **Python** (Pandas, NumPy, Scikit-Learn)
- **Data Visualization:** Matplotlib, Seaborn, Plotly
- **Interactive Mapping:** Folium
- **Web App:** Plotly Dash
- **Database:** SQLite & SQL
